## 👁️ What is `gaslight.exe`?

You visit YouTube to watch a recipe.  
You click **"Skip Ad"**, but for a split second, it reads **"Accept Your Fate"**.  
You search for music, but the placeholder whispers **"Investigate the inevitable"**.  
You try to log out, but the button says **"Flee"**.

`gaslight.exe` is a Manifest V3 browser extension engineered to turn routine web browsing into an atmospheric ARG / psychological thriller. It doesn't break the web—it slowly persuades you that *the web has always been this way*.

## ⚡ Key Features

```
┌─────────────────────────────────────────────────────────────┐
│                       gaslight.exe                          │
├─────────────────┬───────────────────┬───────────────────────┤
│ 📝 DOM Mutation │ 🎚️ Escalation     │ 🧠 Memory System      │
│ MutationObserver│ Stages 0 to 3     │ Local event & click   │
│ real-time text  │ progresses with   │ tracking to cite past │
│ re-writing      │ session time      │ behavior at you       │
├─────────────────┼───────────────────┼───────────────────────┤
│ 🔊 Web Audio    │ 🌀 Dynamic Warp   │ 🛡️ Safe & Accessible  │
│ 100% procedural │ Mouse-reactive    │ Reduced motion,       │
│ audio synthesis │ drifting & DOM    │ panic reset button,   │
│ (no soundfiles!)│ physics decay     │ 0% server telemetry   │
└─────────────────┴───────────────────┴───────────────────────┘
```

- **Mutation Distortion Engine**: Uses a lightweight batched `MutationObserver` to scan and transmute text nodes, `aria-label`s, and `placeholder`s without degrading frame rates.
- **The Escalation System**: The longer a session lasts, the deeper the rabbit hole:
  - `STAGE 0: NORMAL` — Everything seems normal... *almost*.
  - `STAGE 1: SUSPICIOUS` — Occasional subtle wording shifts.
  - `STAGE 2: SOMETHING IS WRONG` — Visible warping, sound anomalies, micro-delays.
  - `STAGE 3: THE INTERNET KNOWS` — Full algorithmic breakdown and unhinged system alerts.
- **Procedural Web Audio Engine**: Zero MP3/WAV assets. Every whisper, click, low-frequency hum, and static burst is synthesized in real time via the browser's native `AudioContext`.
- **Local Memory Engine**: Tracks your clicks, repeated searches, and session milestones in `chrome.storage.local`, periodically echoing them back to you when you least expect it.
- **The Descent Log**: An in-browser chronicle of all anomalies and clues discovered during your browsing sessions.

## 🚀 Installation

### Load Unpacked (Chrome / Brave / Edge / Chromium)

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/gaslight-exe.git
   ```
2. Open your Chromium browser and navigate to:
   ```
   chrome://extensions/
   ```
3. Toggle on **Developer mode** (top right switch).
4. Click **Load unpacked** (top left).
5. Select the root project folder (`gaslight-exe-hehe`).
6. Pin `gaslight.exe` to your toolbar, open YouTube, and observe reality begin to fray.

## 🕹️ Controls & Configuration

Click the extension icon to summon the Control Deck:

- **Master Switch**: Instantly toggle distortion on/off.
- **Personality Matrix**: Swap between `Passive-Aggressive`, `Paranoid`, `Cosmic Horror`, and `Evil Corporate`.
- **Chaos Intensity Slider (0 – 100%)**:
  - `0 - 30%`: Barely perceptible. You'll question your own eyes.
  - `30 - 70%`: Distinct uncanny valley. Unmistakably surreal.
  - `70 - 100%`: Full digital delirium.
- **Sound Effects Toggle**: Enable procedural audio whispers and frequency shifts.
- **Granular Toggles**: Selectively enable/disable text replacement, visual warps, memory tracking, and dynamic physics.

### 🛟 Safety & Accessibility
We take user comfort seriously. Located right inside the popup and options page:
- **Accessibility Mode**: Disables visual distortion effects for photosensitive or motion-sensitive users.
- **Reduce Motion**: Turns off screen warps, floats, and CSS jitters.
- **Panic Button (`RESET ENTIRE EXPERIENCE`)**: Clears memory logs, wipes storage, and returns all interfaces to normal instantly.

## 🔒 Privacy Guarantee

> **Not a single byte leaves your machine.**

- `gaslight.exe` uses `chrome.storage.local` exclusively.
- No analytics. No external APIs. No remote trackers.
- Your searches, click counts, and session memories are ephemeral and strictly confined to your local browser sandbox.
