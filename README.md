# gaslight.exe

Ever visited a website and felt like something was slightly off? Probably nothing.

gaslight.exe is a Chrome extension that distorts cosmetic interface text, remembers selected interactions, and gradually develops an increasingly suspicious personality.

It starts with 'Skip Ad' becoming 'Accept Your Fate.'

It ends with the internet asking why you keep coming back.

## Installation

1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right.
4. Click "Load unpacked" and select the extension directory.
